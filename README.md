🖥️ О проекте

View_Repository — небольшой архив и просмотрщик версий TLWebsite.

Основная идея проекта заключается в том, чтобы не удалять старые версии сайта, а сохранять их отдельно и иметь возможность открыть любую из них.

TLWebsite
   │
   ├── V1 ──► первая основа
   │
   ├── V2 ──► мобильная адаптация
   │
   ├── V3 ──► новый интерфейс
   │
   └── V4 ──► современная и компактная версия

«💡 Каждая версия является отдельным HTML-файлом и может быть открыта независимо от остальных.»

🌐 Просмотр версий

Для просмотра используется "index.html".

Он автоматически получает список HTML-файлов репозитория через GitHub API и позволяет выбрать нужную версию.

После выбора файл открывается как полноценная веб-страница, а не как исходный код.

Пример

index.html
    │
    ▼
GitHub API
    │
    ▼
Поиск .html файлов
    │
    ├── TL_V1.html
    ├── TL_V2.html
    ├── TL_V3.html
    └── TL_V4.html
            │
            ▼
      Выбор версии
            │
            ▼
    Открытие сайта

💡 Зачем нужен этот репозиторий?

Проект создан прежде всего для сохранения истории разработки.

Вместо того чтобы постоянно перезаписывать один HTML-файл:

TLWebsite.html

каждая значимая версия сохраняется отдельно:

TL_V1.html
TL_V2.html
TL_V3.html
TL_V4.html

Это позволяет в любой момент вернуться к старой версии и посмотреть, как проект выглядел раньше.

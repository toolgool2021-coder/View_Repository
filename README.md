# ⟦ TL ⟧ View Repository

Архив версий **TLWebsite**.

Здесь сохраняются отдельные версии проекта, чтобы можно было посмотреть историю его развития и сравнить изменения между версиями.

**[Открыть View Repository →](https://toolgool2021-coder.github.io/View_Repository/)**

---

## Версии

| Версия | Основные изменения |
|:---:|---|
| **V1** | Первая полноценная версия, GitHub API, дерево файлов, `iframe` |
| **V2** | Мобильная адаптация, drawer, модальные окна, просмотр файлов |
| **V3** | Новый интерфейс, glass-эффекты, анимации, обновлённый drawer |
| **V4** | Компактный интерфейс, загрузочный экран, обновлённый просмотрщик |

---

## V1

Первая полноценная версия TLWebsite и основа последующих версий.

### Основное

- GitHub API
- дерево файлов репозитория
- просмотр сайта через `iframe`
- HTML, CSS и JavaScript
- изображения, SVG, видео и аудио
- обработка относительных путей
- обработка CSS `url()`
- поддержка `@import`
- JavaScript module imports
- тёмный интерфейс

V1 заложила техническую основу проекта.

---

## V2

Вторая версия была сосредоточена в первую очередь на удобстве использования с телефона.

### Основное

- адаптивный интерфейс
- мобильная панель
- выдвижное меню файлов
- затемнение фона
- просмотр исходного кода
- просмотр изображений
- модальные окна
- окно открытия URL
- более компактное управление

V2 стала заметно удобнее на небольших экранах.

---

## V3

Крупное визуальное обновление проекта.

### Основное

- новый верхний интерфейс
- логотип TL
- стеклянные элементы
- `backdrop-filter`
- новый drawer
- анимации открытия и закрытия
- затемнение фона
- переработанные модальные окна
- отдельный просмотрщик файлов
- просмотр исходного кода
- улучшенный экран загрузки
- обработка ошибок
- адаптация под небольшие экраны

V3 изменила не только внешний вид, но и структуру интерфейса.

---

## V4

Более компактное продолжение V3.

### Основное

- переработанная верхняя панель
- быстрый доступ к репозиторию
- быстрая перезагрузка
- быстрый доступ к файлам
- обновлённый список файлов
- экран загрузки
- анимация загрузки
- просмотр исходного кода
- сохранённая мобильная адаптация
- обновлённые размеры и отступы
- более минималистичный интерфейс

Главная идея V4 — убрать всё лишнее и оставить максимум места самому просматриваемому проекту.
